# Receh — halaman publik

Halaman publik aplikasi Receh (pencatat pengeluaran harian dengan scan struk).

- [`privacy-policy.html`](privacy-policy.html): Kebijakan Privasi, untuk Google Play Console dan layar Branding OAuth di Google Cloud.
- [`privacy-policy-en.html`](privacy-policy-en.html): Privacy Policy dalam bahasa Inggris, untuk listing Play Store berbahasa Inggris dan pesan GDPR AdMob.
- [`delete-account.html`](delete-account.html): cara menghapus akun dan data, untuk isian "Hapus URL akun" di Data Safety.
- `index.html`: mengarahkan ke kebijakan privasi.

Jika di-host dengan GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`),
URL kebijakan privasinya menjadi:

```
https://<username>.github.io/Receh-Public/privacy-policy.html
```
